# プレイスキン置き場

自分用につくったもの
動作確認は開発者が手に入った最新のbeatorajaでのみ行う (2026/01現在0.8.8)

## play

27inch モニター、43inch モニターに両対応するプレイスキン
それぞれのモードで設定を共用でき、43inch AC 幅相当のスキンにする

レイアウトは既存のゲームには寄せず、パーツはプレイに必要なものだけ用意する
27inch は真ん中表示、43inch はまずは右サイドに対応させる

### 没機能

#### プレイ中のランダム配置表示

beatorajaの2026/01/23のmasterではリザルト画面上でしか取得できないオプションだった(NUMBER 450~470あたり)
luaの範囲内で計算するのは厳しいと考えられる
(ネット上の譜面データと突き合わせて計算できる可能性はあるが、本体をバージョンアップするほうがマシそう)
