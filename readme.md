# Simple Smart Skin

基本的に自分用
既存のSkinをカスタマイズしようとすると主に読むのがつらいため作成

動作確認は開発者が手に入った最新のbeatorajaでのみ行う (2026/01現在0.8.8)
本流以外にのみ存在する機能については対応予定なし

## インストール

このリポジトリの内容をskinフォルダ以下に置く

`skin/SSSkin/play`

のようになっていればよし

## 各種画面

現状Playのみ

### play

27inch モニター、43inch モニターに両対応するプレイスキン
それぞれのモードで設定を共用でき、いわゆる AC 幅相当のスキンにする予定

レイアウトは既存のゲームには寄せず、パーツはとりあえずプレイに必要そうなものだけ用意する
27inch は真ん中表示、43inch はまずは右サイドに対応させる

#### できていない機能

- 43inchレイアウト
- フルコン演出
- 曲終了演出
- 曲残り時間/残りノーツ等の表示
- 現在時刻表示
- 各種UIの説明文字

#### 没機能

##### プレイ中のランダム配置表示

beatorajaの2026/01/23のmasterではリザルト画面上でしか取得できないオプションだった(NUMBER 450~470あたり)
luaの範囲内で計算するのは厳しいと考えられる
(ネット上の譜面データと突き合わせて計算できる可能性はあるが、本体をバージョンアップするほうがマシそう)
