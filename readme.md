# Simple Smart Skin

基本的に自分用
既存のSkinをカスタマイズしようとすると主に読むのがつらいため作成

動作確認は開発者が手に入った最新のbeatorajaでのみ行う (2026/01現在0.8.8)
本流以外にのみ存在する機能については対応予定なし

## インストール

このリポジトリの内容をskinフォルダ以下に置く

`skin/SSSkin/play`

のようなフォルダ構造になっていればOK

## 各種画面

現状Playのみ

### play

27inch モニター、43inch モニターに両対応するプレイスキン
それぞれのモードで設定を共用でき、いわゆる AC 幅相当のスキンにする予定

レイアウトは既存のゲームには寄せず、パーツはとりあえずプレイに必要そうなものだけ用意する
27inch は真ん中表示、43inch はまずは右サイドに対応させる

#### オフセット

現状はデフォルトのオフセットのみ対応
各種値は負の値を入れると逆の効果になる

##### All offset(%)

画面全体の描画に補正をかける

| 項目 | 単位 |             効果              |
| :--: | :--: | :---------------------------: |
|  x   |  %   | 画面全体を `x` % 右に描画する |
|  y   |  %   | 画面全体を `y` % 上に描画する |
|  w   |  %   | 画面全体を `w` % 右に拡大する |
|  h   |  %   | 画面全体を `h` % 上に拡大する |

##### Notes offset

ノーツの太さを変える

| 項目 | 単位 |              効果              |
| :--: | :--: | :----------------------------: |
|  h   |  px  | ノーツを `h` px 上下に拡大する |

##### Judge offset

判定文字の描画を調整する

| 項目 |  入力値  |                                              効果                                              |
| :--: | :------: | :--------------------------------------------------------------------------------------------: |
|  x   |    px    |                                 判定文字を `x` px 右に描画する                                 |
|  y   |    px    |                                 判定文字を `y` px 上に描画する                                 |
|  w   |    px    |                                判定文字を `w` px 左右に拡大する                                |
|  h   |    px    |                                判定文字を `h` px 上下に拡大する                                |
|  a   | -255 ~ 0 | 判定文字の不透明度を `a` 上げる <br> 透明度を下げたい分のマイナス値を入れる -255にすると消える |

##### Judge Detail offset

判定文字周辺の文字(ゴースト、fast/slow)の描画を調整する
入力可能項目は Judge offset と同様
